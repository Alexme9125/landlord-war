# Darwin斗地主规则 v1

规则参考[传统欢乐斗地主公开资料](https://www.gamersky.com/handbook/201411/487912.shtml)。腾讯不同平台、年代与房间可能不同，尤其是底牌奖励。本文件是本项目唯一规则标准，不宣称复刻腾讯现行所有规则。

## 发牌与叫抢

54 张牌，三人各 17 张，留三张底牌。每局使用服务器安全随机数洗牌、随机首叫者。

按逆时针顺序叫 / 不叫，全部不叫则重发；有人叫后，其余没有选择“不叫”的玩家依次抢 / 不抢。出现其他玩家抢地主时，首叫者最后再选择一次抢 / 不抢。最后叫 / 抢者为地主。首次叫不翻倍，每次抢翻倍。

地主收三张公开底牌。在四癞子模式中，此时从 3 至 2 随机选择一个点数，该点数的四张牌为癞子；叫抢阶段不提前公开或向 AI 提供癞子点数。

亮底牌后三人各有一次独立的 ×1 / ×2 选择，在大家都决定或超时后统一公开。没有明牌、超级加倍和余额门槛。地主首先出牌。

## 牌型

普通点数为 `3 < 4 < … < 10 < J < Q < K < A < 2 < 小王 < 大王`，花色不比大小。同类同张数同主体长度按主体最大点数比较；炸弹和王炸可压普通牌。

| 牌型 | 条件 |
| --- | --- |
| 单张 / 对子 / 三张 | 相同点数的 1 / 2 / 3 张，王只能单出或组成王炸 |
| 三带一 / 三带对 | 三张同点数，加一个不同点数单张 / 对子 |
| 顺子 | 3 至 A 的至少五张连续单牌 |
| 连对 | 3 至 A 的至少三组连续对子 |
| 飞机 | 3 至 A 的至少两组连续三张 |
| 飞机带单 | 每组三张带一张；允许对子拆作两单，禁止双王同时出现、四张同点数翼牌和主体点数翼牌 |
| 飞机带对 | 每组三张带一对；翼牌对子点数各不相同，不与主体相同 |
| 四带二单 | 四张同点数加两张，允许带一对，不允许同时带双王 |
| 四带两对 | 四张同点数加两个不同点数的对子，不与主体相同 |
| 炸弹 | 四张同点数 |
| 王炸 | 小王加大王 |

四带二不是炸弹，不增加倍率。2 和王不能进入任何连续主体。

癞子可以替代 3 至 2，不能替代王。全由癞子组成的单张、对子、三张按原点数使用；四张为纯癞子炸弹。与非癞子混合的四张炸弹是软炸，四张非癞子同点数为硬炸。大小为 `王炸 > 纯癞子炸 > 硬炸 > 软炸`，同级炸弹按点数比较；不设长炸弹。底牌奖励不使用癞子替代。

选择多张牌产生多种合法解释时，玩家确认具体出法；服务器再次验证替代点数与物理牌。提示是有限候选搜索，不保证列出所有最优策略。

轮到跟牌可不出；两人连续不出后，由最后出牌者重新领出，领出不能不出。任一玩家出完即结算：地主出完地主胜，任一农民出完两名农民共同胜。

## 倍率与结算

| 公共事件 | 倍率 |
| --- | --- |
| 基础 | 15 |
| 每次抢地主 | ×2 |
| 底牌单王、同花、三张顺子 | ×2 |
| 底牌双王、三条、同花顺 | ×4 |
| 标准炸弹、王炸 | ×2 |
| 癞子软炸 | ×2 |
| 癞子硬炸、纯癞子炸、王炸 | ×4 |
| 春天 / 反春天 | ×2 |

底牌奖励只取最高的一项，不叠加。底牌顺子只能在 3 至 A 内（QKA 可以、KA2 不可以）；王没有普通花色。持有炸弹不计倍，实际打出才计倍。

地主赢且两名农民一手未出为春天；农民赢且地主仅出过一手为反春天。两者只能触发一个，退出判负不触发。

每名农民独立与地主结算：

`理论金额 = 本局底注 × 公共倍数 × 地主个人加倍 × 该农民个人加倍`

底注可选 10 / 20 / 50 Tokens，默认 10。主界面所选底注用于新建 PVE / PVP；PVP 房主与 PVE 玩家也可在两局之间修改。修改后所有真人需重新准备，开局后本局底注锁定；无人叫地主重发不改变底注。结算和回放保留原局底注，公共倍数仍从 ×15 开始。

地主输赢是两笔之和，农民之间不转账。比如底注 10、公共 ×60、地主 ×1、农民甲 ×2、乙 ×1，甲与地主理论金额为 1200 Tokens，乙与地主为 600 Tokens。

金额全部使用整数。没有倍率或理论输赢上限，不允许负余额：

- 地主胜：每名农民各付 `min(自己的余额, 理论应付)`，地主收到两笔之和。
- 地主负：最多付出现有余额，两名农民按理论应得金额的比例分配；除法余数按最大余数法分配，同余按座位顺序。
- 同一对局的实际扣款合计等于实际奖励合计，无抽水；结算幂等，重复请求不会重复扣款。
- 同一游客不能并发参与多局。余额为零不能准备，可回答百以内加法领取 10 KTokens；每次破产均可领取，没有次数上限。题目五分钟有效且只能使用一次。答错显示“这都答不对的人是不配领救济的”，作废旧题并给出一道不同的新题；余额保持不变，可继续作答。
- 在主界面点击 Tokens 旁的重置按钮，经两次确认可将余额直接设为 100 KTokens（不是额外增加 100 KTokens）。取消不修改余额，重置不清除昵称、战绩或回放；在任何房间内均不可重置。
- 初始玩家钱包为 100 KTokens。PVE 每名机器人每局重置为 100 KTokens，仍按余额结算；玩家钱包持久保留。PVE、救济与主动重置会影响系统货币总量，不是封闭经济。

## 房间、计时与退出

六位房间码，三名玩家全部准备自动开局。满座时进入观战；非游戏期间可站起、坐空座。房主离开自动移交，房间玩法创建后不可更改。观众只看公开信息，结算后可在房间查看全牌回放；持久历史仅对本局参与者开放。

叫抢和主动加倍各 15 秒，出牌 30 秒。超时默认不叫 / 不抢 / 不加倍；跟牌不出，领出最小单张。

主动退出立即结束：确定地主前作废，不变动余额；确定地主后判退出者所属阵营负，以当前公共倍数结算。如果个人加倍尚未统一公开，则三人的个人倍率均按 ×1 结算。

玩家网络断开时暂停，保留 60 秒，重连后继续原剩余时间；超时按退出处理。其他观众的断线和离开不影响牌局。服务重启使未结算对局作废；钱包和已完成记录由 SQLite 持久保存。
